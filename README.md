# 재무제표로 미래 부도 기업을 예측할 수 있을까?

## 1. 분석 질문
기업의 재무 비율로 1년 후 부도 여부를 미리 맞힐 수 있는가?
어떤 재무 신호가 부도를 가장 잘 가르는가?

## 2. 데이터
- 출처: [UCI Polish Companies Bankruptcy Data](https://archive.ics.uci.edu/dataset/365/polish+companies+bankruptcy+data) (5year 파일)
- 내용: 폴란드 기업의 재무 비율 64개, 1년 후 부도 여부
- 크기: 5,910개 기업 × 65열
- 타깃: `class` (부도 1 / 정상 0), 부도 비율 약 7% → 불균형

## 3. 데이터 확인 결과
- 결측: `Attr37`((유동자산 - 재고자산) / 장기부채)이 43.1%로 가장 많음
  - 장기부채가 0이라 계산되지 않은 것으로 추정
  - 결측 기업의 부도율 8.2% vs 비결측 기업 5.9% (약 1.4배, 카이제곱 검정 p ≈ 0.0007)
  - 나머지 변수는 결측 비율이 작음
- 이상치: `Attr4`, `Attr5`, `Attr61`~`Attr64`에서 극단값 확인
  - 분모가 0에 가까운 비율에서 값이 폭발하는 계산상 문제로 판단

## 4. 전처리
| 처리 | 로지스틱 회귀 | 랜덤포레스트 | LightGBM |
|---|---|---|---|
| Attr37 | 결측 여부 플래그(`no_LT_debt`) 생성 후 삭제 | 동일 | 동일 |
| 나머지 결측 | 중앙값 | 중앙값 | 그대로 (모델이 자체 처리) |
| 이상치 | 상하위 1% 자르기 | 그대로 | 그대로 |
| 스케일링 | StandardScaler | 불필요 | 불필요 |
| 불균형 | `class_weight='balanced'` | 동일 | 동일 |

- 데이터 누수를 막기 위해 결측 대치·이상치 처리·스케일링은 파이프라인 안에서 학습 데이터 기준으로만 계산

## 5. 모델링
- 기준: 전부 정상으로 예측 (정확도 약 93%, 재현율 0%)
- 비교 모델: 로지스틱 회귀 → 랜덤포레스트 → LightGBM

## 6. 평가
- 5-fold 층화 교차검증 (각 묶음의 부도 비율을 약 7%로 동일하게 유지)
- 지표: 재현율(최우선), 정밀도, F1, ROC-AUC
- 정확도는 불균형 때문에 주 지표로 쓰지 않음

## 7. 해석 계획 (다음 과제)
- 중요도 상위 변수를 수익성·안정성·유동성·활동성으로 묶어 해석
- 로지스틱 회귀 계수로 부도 위험을 올리는 방향과 내리는 방향 확인
- 장기부채 없음 플래그가 실제로 중요한 신호인지 확인

## 8. 한계

- Attr37 결측 이유는 추정
